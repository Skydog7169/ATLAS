# ATLAS review — batch 9: Front door and provenance

You are implementing one batch of fixes from a verified product/design review of ATLAS (this repository: an interactive geopolitics map, React 19 + TypeScript + Vite + d3-geo; read README.md first). The full review, with screenshots for every issue, is the private artifact https://claude.ai/artifact/ToM4rKDum5NieNMtCtGWcS — if your Artifact tool can read it, use it for the screenshots; everything you need to act on is also below. Issue refs (I1, I2 …) match the review.

This is wave 2. Wave 1 batches (data truth, palette, navigation, camera/mobile, what-changed, search/loading) have merged or are merging into `main`; start from the latest `main` and build on what they did rather than duplicating it. Two other wave-2 sessions run in parallel: batch 7 — Honest time and embeds; batch 8 — Visible map state and dismissible overlays. You own: the landing state and a This week card, provenance/definitions next to claims in DetailPanel.tsx, labels.ts definitions, dossier.ts status wording, research-pass output fields in scripts/research/update.mjs and schema.ts if needed. Avoid: anything wave 1 already changed beyond what this batch needs.

## The moves

### Replace the front door with a promise and a 'This week' card
Why: The bloc-count choropleth answers no question, is biased by which blocs were curated, and puts selection cyan on three countries. Nothing on screen says what ATLAS is, and the header readouts are opaque. The first screen should show what ATLAS is good at: current, sourced, dated judgement about who is fighting and what changed.

What: Open first-time visitors on a 'Now' view: Conflicts mode with theatre-only fills from item 1 and halos on escalated or eased situations, with Blocs one click away. Alternatively, use neutral land with the chips as the call to action. Replace 'GEOPOLITICAL AWARENESS' with 'Who's allied, who's fighting, what changed. Every claim sourced and dated.' Header: '31 CONFLICTS · 32 UNREST · 18 BLOCS' and a never-hidden 'UPDATED 20 OCT' button; the clock moves to briefing only. On first visit, show a dismissible 'This week' card driven by the delta engine (New / Escalated / Eased, top 3 with date and link) that includes a one-line 'AI-researched from cited sources, editor-approved' note. Conflict panels open with a 'Latest · date' block. Drop the duplicate backer chip row and move Recent changes up in dossiers. Name the feature 'Latest changes' everywhere.

### Put provenance and definitions next to the claims
Why: AI drafting is not disclosed next to the text. 'Verified' overstates what the pipeline checks. Half the citations are tracker homepages. Intensity and confidence are never defined, disputed-territory labels take sides, and there are seven freshness verbs. For journalists and teachers working under AI-disclosure rules, disclosure up front costs little and discovery later costs credibility.

What: Under each assessment, add a provenance line: 'AI-drafted (Claude, web search) from 3 cited sources · approved by an editor 19 Oct 2026'. Change 'verified' to 'updated' and keep 'Checked, no change'. Render sources as 'Outlet: Headline (date)'. Show homepages as a muted 'Background reference', and have update.mjs reject homepage-only citations. Add INTENSITY_DEF and confidence definitions as legend sub-lines and badge titles, rename latent to 'Latent (standoff or ceasefire)', and give unrest its own labels. Add curated status, name and capital overrides for TWN, PSE, UNK, ESH and ISR, plus an About section on disputed territories. Use one en-GB date format and four freshness verbs, with an amber 'May be out of date' chip. Restructure About into headed blocks. Add chokepoints to the daily hot list.

1. `git fetch origin main && git checkout -b claude/review-frontdoor origin/main`, then `pnpm install`.
2. Verify each issue still reproduces before fixing it (the review ran against main at commit 81bae1e).
